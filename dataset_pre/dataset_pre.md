# AIS CT 数据预处理

## 1. 处理目标

将已去颅骨的 3D 头颅 CT 与对应脑梗标签处理成统一的 NIfTI 数据，供后续 2D 切片训练和病例级 3D 评估使用。

处理入口为 [`preprocess_ais_ct.py`](./preprocess_ais_ct.py)。预处理只进行固定 HU 窗截断，不执行 min-max 或 z-score 归一化，以兼容初始化范围为 `17.5–22 HU` 的先验模块。

## 2. 输入要求

每个病例必须包含同名的 CT 和标签文件：

```text
images_after_skull/
├── 1.nii.gz
├── 2.nii.gz
└── ...

Stroke_label/
├── 1.nii.gz
├── 2.nii.gz
└── ...
```

输入数据必须满足：

- CT 和标签均为 3D NIfTI 文件；
- CT 已完成去颅骨，脑外背景值为 `0`；
- CT 强度为 HU，而不是 `[0,1]`、`[0,255]` 或 z-score 数据；
- 标签为二值图：`0` 表示非脑梗，`1` 表示脑梗；
- CT 与标签文件名完全一致；
- CT 与标签的尺寸、spacing、origin 和 direction 一致；
- CT 不包含 NaN 或 Inf。

如果输入来自原三分类 labelmap，转换方式为：

```python
lesion_mask = (labelmap == 2).astype(np.uint8)
```

新项目统一采用二分类：

| 标签值 | 含义 |
| ---: | --- |
| 0 | 非脑梗 |
| 1 | 脑梗 |

## 3. 处理流程

### 3.1 脑区提取

去颅骨 CT 使用 `0` 表示脑外背景，因此首先生成候选脑区：

```python
image != 0
```

然后依次执行：

1. 3D 形态学闭运算，填补小间隙；
2. 连通域分析；
3. 保留最大连通域；
4. 3D 孔洞填充。

脑区提取必须在 HU 截断和重采样之前进行。

### 3.2 3D 脑区裁剪

根据脑区 mask 计算三维包围盒，并设置物理边缘：

```text
margin_mm = (10, 10, 0)
```

即 X、Y 方向各扩展 `10 mm`，Z 方向不额外扩展。CT、脑区 mask 和标签使用完全相同的包围盒裁剪。

### 3.3 HU 窗截断

脑区内 CT 截断到：

```text
[-20, 100] HU
```

对应窗位 `40 HU`、窗宽 `120 HU`。处理规则为：

```python
output = np.zeros_like(array, dtype=np.float32)
output[brain] = np.clip(array[brain], -20, 100)
```

注意：

- 只截断，不映射到 `[0,1]`；
- 脑区内保留 HU 数值语义；
- 脑外背景保持为 `0`；
- `0` 不在先验阈值 `17.5–22 HU` 内，不会直接触发先验响应。

### 3.4 XY 等比例缩放与补边

保持 XY 宽高比，将较长边缩放至 `256`，然后居中补边到 `256×256`。

- CT 使用线性插值，输出类型为 `float32`；
- 标签使用最近邻插值，输出类型为 `uint8`；
- Z 轴层数和 Z 向 spacing 保持不变；
- CT 与标签的补边值均为 `0`；
- 重采样后再次验证标签只能包含 `0/1`。

## 4. 输出结构

```text
processed/
├── images/
│   ├── 1.nii.gz
│   └── ...
├── masks/
│   ├── 1.nii.gz
│   └── ...
└── metadata/
    ├── 1.json
    └── ...
```

使用 `masks` 作为标签目录名，与项目中的 `DataSetFFM` 接口保持一致。

## 5. 元数据

每个病例对应一个 JSON 文件，记录：

- 原脑区裁剪包围盒 `bbox`；
- 缩放后的尺寸 `resized_size`；
- 目标 XY 尺寸 `target_xy`；
- 补边参数 `padding`；
- 强度单位、HU 窗、归一化方式和背景填充值。

示例：

```json
{
  "resized_size": [256, 218, 32],
  "padding": [0, 19, 0, 0, 19, 0],
  "bbox": [40, 55, 0, 420, 360, 32],
  "target_xy": [256, 256],
  "intensity": {
    "unit": "HU",
    "window": [-20, 100],
    "normalization": null,
    "background_fill": 0
  }
}
```

## 6. 运行方式

修改 `preprocess_ais_ct.py` 末尾的输入和输出目录：

```python
run(
    image_dir="去颅骨 CT 目录",
    label_dir="二值脑梗标签目录",
    output_dir="输出目录",
)
```

然后在项目根目录运行：

```powershell
python dataset_pre/preprocess_ais_ct.py
```

## 7. 自动检查与报错

脚本会检查：

- 输入目录是否存在；
- CT 目录是否包含 `.nii.gz` 文件；
- CT 与标签文件名是否一一对应；
- CT 和标签是否均为 3D；
- CT 与标签的尺寸、spacing、origin 和 direction 是否一致；
- CT 是否包含 NaN 或 Inf；
- 是否能够检测到有效脑区；
- 输入和重采样后的标签是否只包含 `0/1`。

任一检查失败时会直接报错，不应忽略错误后继续训练。

## 8. 预处理质量检查

正式训练前至少检查：

1. 所有输出 CT 的 XY 尺寸均为 `256×256`；
2. CT 数据类型为 `float32`；
3. 脑区内 CT 数值位于 `[-20,100] HU`；
4. 脑外区域与补边为 `0`；
5. 标签类型为 `uint8`，唯一值只能是 `[0]` 或 `[0,1]`；
6. CT 与标签在每个病例中空间对齐；
7. 病灶没有因裁剪或重采样消失；
8. 阳性和阴性病例数量与原始数据一致；
9. 同一患者的所有切片和时间点只属于一个数据划分。

建议重点抽查小病灶、脑边缘病灶、异常 spacing、高密度异常值及阴性病例。

## 9. 后续切片与训练接口

将 NIfTI 按轴向切片保存为 `.pt` 后，目录保持为：

```text
dataset/
├── images/
└── masks/
```

模型及相关模块统一使用：

```python
num_classes = 2
```

先验模块的初始化参数保持 HU 单位：

```python
init_lower = 17.5
init_upper = 22.0
init_tau = 2.5
```

如果以后重新启用 `[0,1]` 缩放，必须同时换算 `lower`、`upper` 和 `tau`，不能只改变 CT 数值域而保留 HU 阈值。

## 10. 数据划分要求

必须先按患者划分训练集、验证集和测试集，再生成切片索引或训练清单：

- 禁止按 2D 切片随机划分；
- 同一患者的不同扫描时间点不得跨集合；
- 数据增强只能应用于训练集；
- CPAISD 外部测试集不得参与训练、阈值选择或超参数调整；
- 所有对比模型必须使用相同的患者级划分。
